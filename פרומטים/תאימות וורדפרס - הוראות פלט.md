# תאימות וורדפרס - הוראות פלט לעמודי תוכן

מסמך זה מיועד לכל סוכן AI שמייצר או עורך HTML עבור עמודי וורדפרס.
**חובה לתייג את הקובץ הזה** (`@תאימות וורדפרס - הוראות פלט.md`) בכל סשן שמייצר פלט HTML.

---

## הבעיה המרכזית: wpautop

וורדפרס מפעיל פונקציה בשם `wpautop` על כל תוכן בבלוק Custom HTML.
הפונקציה ממירה **כל שורה ריקה** לתגי `<p></p>`.

**מה זה שובר:**
- שורה ריקה בתוך `<style>` → מכניס `<p>` באמצע CSS → העיצוב נעלם
- שורה ריקה בתוך `<script>` → מכניס `<p>` באמצע JS → שגיאת SyntaxError
- שורה ריקה בתוך JSON-LD → שובר את ה-Schema Markup

**הכלל העליון:** כל בלוק `<style>`, `<script>`, ו-JSON-LD חייב להיות **מכווץ (minified) לשורה אחת בלבד**. אסורות שורות ריקות בכל הקובץ.

---

## מבנה הקובץ

### שורה ראשונה ואחרונה

```
<!-- wp:html -->
...כל התוכן...
<!-- /wp:html -->
```

### div ראשי

כל התוכן (כולל style ו-script) עטוף ב-div אחד:

```html
<div class="edit-hoverable" dir="rtl" style="text-align: right; max-width: 1200px; margin: 0 auto; padding: 0 20px;">
...
</div>
```

### אפס שורות ריקות

אסורות שורות ריקות בכל הקובץ. בין אלמנטים — שורה חדשה רגילה בלבד.

שגוי:
```
<p>פסקה ראשונה</p>

<p>פסקה שנייה</p>
```

נכון:
```
<p>פסקה ראשונה</p>
<p>פסקה שנייה</p>
```

## כללי כיווץ (Minification)

### CSS — מכווץ לשורה אחת

שגוי:
```html
<style>
.my-class {
  color: red;
  font-size: 16px;
}
</style>
```

נכון:
```html
<style>.my-class{color:red;font-size:16px}</style>
```

כללים:
- הסר כל מעברי שורה ורווחים מיותרים
- **השאר** `!important` (קריטי לדריסת עיצוב תבנית)
- השאר `;` בין מאפיינים

### JavaScript — מכווץ לשורה אחת

שגוי:
```html
<script>
(function() {
  'use strict';
  var x = 1;
  console.log(x);
})();
</script>
```

נכון:
```html
<script>(function(){'use strict';var x=1;console.log(x)})();</script>
```

כללים:
- הסר כל מעברי שורה
- שמור רווח אחרי `var`, `if`, `function`, `return`
- השאר `;` בין פקודות
- הסר הערות `//` ו-`/* */`
- מחרוזות (בתוך גרשיים) — לא לשנות

### JSON-LD Schema — מכווץ לשורה אחת

שגוי:
```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage"
}
</script>
```

נכון:
```html
<script type="application/ld+json">{"@context":"https://schema.org","@type":"FAQPage"}</script>
```

### רווח אחד בין בלוקים

בין בלוק לבלוק — רווח אחד בלבד, **הכל באותה שורה**.

שגוי:
```
</script>
<style>
```

נכון:
```
</script> <style>
```

## תיקון כותרות (h2, h3)

כותרות h2 ו-h3 נדחפות לשמאל בוורדפרס כי אין להן CSS ייעודי.

**חובה להוסיף בבלוק ה-CSS הסופי:**
```css
h2,h3{max-width:1200px !important;margin-left:auto !important;margin-right:auto !important;text-align:right !important}
```

**מבנה HTML נכון לכותרות:**
```html
<h2 class="edit-hoverable diff-element-new">כותרת</h2>
```

## כפתורי CTA — גלילה לווידג'ט

כפתורי CTA ("בדוק זכאות", "שלח בקשה") חייבים לגלול לטופס (ווידג'ט AWG).
חסרים 4 רכיבים שחייבים לעבוד ביחד:

### רכיב 1: עטיפת הווידג'ט

```html
<div id="loan-form-section" class="form-wrapper-section">[awg postid="XXXX"]</div>
```

### רכיב 2: class scroll-to-form בכפתורים

```html
<a class="wpc-loans-XXXX-cta-btn scroll-to-form wpc-loans-XXXX-cta-btn-red" href="#loan-form-section">טקסט</a>
```

`scroll-to-form` נוסף **בנוסף** לקלאסים הקיימים. הקידומת (XXXX) משתנה בין עמודים.

### רכיב 3: href נכון

כל כפתורי CTA חייבים: `href="#loan-form-section"`

### רכיב 4: CSS + JavaScript בסוף הקובץ

CSS (מכווץ):
```html
<style>.form-wrapper-section{scroll-margin-top:100px !important;margin:30px 0 !important}</style>
```

JavaScript (מכווץ):
```html
<script>(function(){'use strict';var ns='WPC_Loans_ScrollToForm';if(window[ns])return;window[ns]=true;document.addEventListener('click',function(e){var link=e.target.closest('.scroll-to-form');if(!link)return;var href=link.getAttribute('href');if(!href||!href.startsWith('#'))return;e.preventDefault();var targetId=href.substring(1);var targetElement=document.getElementById(targetId);if(targetElement){var offset=100;var elementPosition=targetElement.getBoundingClientRect().top+window.pageYOffset;var offsetPosition=elementPosition-offset;window.scrollTo({top:offsetPosition,behavior:'smooth'})}})})();</script>
```

## FAQ — שאלות ותשובות (אקורדיון)

### מבנה HTML

```html
<div class="wpc-loans-XXXX-faq-container">
<div class="wpc-loans-XXXX-faq-item">
<div class="wpc-loans-XXXX-faq-header" tabindex="0" role="button" data-action="toggle-faq">שאלה?</div>
<div class="wpc-loans-XXXX-faq-content" style="max-height: 0px;"><p>תשובה</p></div>
</div>
</div>
```

מרכיבים קריטיים:
- `data-action="toggle-faq"` — ה-JS מזהה לחיצה לפי זה
- `tabindex="0"` — ניווט במקלדת
- `role="button"` — נגישות
- `style="max-height: 0px;"` — תוכן מוסתר בברירת מחדל
- **לא להשתמש ב-`<button>`** — רק `<div>`

## סדר בלוקים בסוף הקובץ

1. סוף תוכן HTML (פסקאות, לינקים, FAQ HTML)
2. `<script type="application/ld+json">{...מכווץ...}</script>`
3. `<style>...CSS ראשי מכווץ...</style>`
4. `<script>...FAQ JavaScript מכווץ...</script>`
5. `<style>...form-wrapper-section + h2,h3 מכווץ...</style>`
6. `<script>...ScrollToForm JavaScript מכווץ...</script>`
7. `</div>`
8. `<!-- /wp:html -->`

**בין כל בלוק לבלוק — רווח אחד בלבד, הכל באותה שורה.**

## שגיאות נפוצות

- לא לשים שורה ריקה בתוך `<style>` או `<script>`
- לא לשים CSS/JS מרובה שורות
- לא לשכוח `data-action="toggle-faq"` ב-FAQ header
- לא לשכוח `scroll-to-form` בכפתורי CTA
- לא לשכוח `id="loan-form-section"` בעטיפת הווידג'ט
- לא לשים `</script>` ו-`<style>` בשורות נפרדות (רק רווח ביניהם)
- לא להשתמש ב-`<button>` ל-FAQ (להשתמש ב-`<div>`)
- לא לשכוח `style="max-height: 0px;"` ב-faq-content
- לא לשכוח `<!-- wp:html -->` ו-`<!-- /wp:html -->`
- לא לפצל Schema למספר בלוקי script (לאחד ל-`@graph` אחד)
