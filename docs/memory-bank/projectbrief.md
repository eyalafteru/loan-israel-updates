# Project Brief

## מה הפרויקט
**עדכון עמודים מיוחדים מאני** — workspace לניהול תוכן, מחשבונים פיננסיים, וכלי אוטומציה עבור אתר loan-israel.co.il (הלוואות ישראל).

## מטרות
1. פיתוח מחשבונים פיננסיים אינטראקטיביים (HTML+JS) להטמעה באתר
2. עדכון ושיפור דפי תוכן קיימים באתר — SEO, שיווק אטומי, UX
3. מעקב אנליטיקס — DataLayer events לכל פעולת copy
4. אוטומציה של תהליכי עבודה — סוכני AI, סקריפטים, QA

## קהלי יעד של האתר
- אנשים שמחפשים הלוואות (משכנתא, חוץ בנקאית, דיגיטלית, בלון וכו')
- אנשים שרוצים לחשב נתונים פיננסיים (ברוטו-נטו, ריבית, עלויות)

## היקף
- ~23 מחשבונים (מוכנים + בפיתוח)
- ~16 דפי תוכן לעדכון
- 7 פרומטים לסוכני AI
- 5 סקריפטי Python + 4 batch files
