# Product Context

## מה המוצר
workspace לניהול, עדכון ופיתוח תוכן ומחשבונים פיננסיים עבור אתר **loan-israel.co.il** — אתר הלוואות ישראלי.

## קהלי יעד
- **לווים פוטנציאליים** — אנשים שמחפשים הלוואות (משכנתא, חוץ בנקאית, בלון, דיגיטלית וכו')
- **משתמשי מחשבונים** — אנשים שרוצים לחשב ברוטו-נטו, עלות רכב, ריבית אפקטיבית וכו'
- **בעלי האתר** — משתמשים ב-workspace הזה לניהול התוכן

## מטרות
1. **מחשבונים פיננסיים** — כלים אינטראקטיביים שמוטמעים באתר (embed code)
2. **תוכן SEO** — דפי תוכן שיווקי מותאמי SEO לנושאי הלוואות
3. **עדכון דפים** — שדרוג דפים קיימים באתר עם תוכן חדש ומחשבונים
4. **מעקב אנליטיקס** — DataLayer events ל-Google Tag Manager

## החלטות מוצריות
- **מחשבונים כ-embed** — כל מחשבון הוא HTML עצמאי שמוטמע באתר WordPress דרך קוד HTML
- **שני כפתורי copy** — כל מחשבון מציע "העתקת קוד הטמעה" (embed) ו"העתקת קוד תצוגה" (preview)
- **שיווק אטומי** — גישה לכתיבת תוכן שיווקי — פירוק לאלמנטים קטנים ושיפור כל אחד
- **פרומטים לסוכנים** — הפרויקט מכיל הוראות מובנות לסוכני AI (QA, SEO, DataLayer, בניית מחשבונים)
