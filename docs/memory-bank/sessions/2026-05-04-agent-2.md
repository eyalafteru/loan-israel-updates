## What Was Done

### WordPress Compatibility — Prompt Updates
The user reported that all new content pages break when uploaded to WordPress (design + functionality). Root cause: WordPress `wpautop` function inserts `<p>` tags into empty lines, breaking CSS, JS, and JSON-LD inside Custom HTML blocks.

The user provided a comprehensive document detailing 4 fixes needed:
1. **Heading display (h2/h3)** — CSS rule for max-width + margin auto
2. **CTA buttons** — scroll-to-form class, loan-form-section wrapper, ScrollToForm JS
3. **FAQ accordion** — data-action="toggle-faq" structure, minified JS/CSS
4. **Full display fix** — zero empty lines, all style/script minified to one line, wp:html wrapper
