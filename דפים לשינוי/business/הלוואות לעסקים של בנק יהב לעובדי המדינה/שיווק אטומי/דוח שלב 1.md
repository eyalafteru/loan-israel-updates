### 8. שכתוב FAQ אטומי ❓

**עקרון:** השאלות טובות, אבל התשובות טכניות מדי. צריך להוסיף "מניסיוננו" ורגש.

#### שאלה 1 - טובה כמו שהיא ✅
```
"האם אני יכול לקבל הלוואה עסקית מבנק יהב בלי להעביר את חשבון העסק?"
```

**תשובה נוכחית:**
```
כן. הלוואות בערבות מדינה זמינות ללקוחות כל הבנקים. גם חלק מההלוואות התקציביות זמינות דרך חשבון תפעולי בלבד, ללא צורך להעביר את כל הפעילות.
```

**תשובה מוצעת (CPBG - ללא תוויות!):**
```
כן - וזו אחת הנקודות החזקות של המסלול הזה.

מניסיוננו, הרבה עובדי מדינה חוששים שברגע שיש עסק, צריך להעביר את הכל לבנק אחד. זה לא נכון. הלוואות בערבות מדינה זמינות ללקוחות כל הבנקים - גם אם אתה לא מעביר את חשבון העסק ליהב. ואפילו חלק מההלוואות התקציביות זמינות דרך חשבון תפעולי בלבד.

אם אתה מרגיש נוח עם הבנק הנוכחי שלך - אין בעיה. תפתח חשבון נוסף רק לצורך ההלוואה.

למה זה חשוב? כי המון אנשים מוותרים על הטבות רק בגלל שחושבים שצריך "לעבור" בנק. לא צריך.
```

#### שאלה 2 - כותרת טובה ✅
```
"מה ההבדל בין הלוואה תקציבית להלוואה עסקית רגילה?"
```

**תשובה נוכחית:**
```
הלוואה תקציבית ניתנת מפיקדון המעסיק (מדינת ישראל) בריבית חשכ"ל - נמוכה משמעותית מהשוק. הלוואה עסקית היא הלוואה בנקאית רגילה, בתנאי שוק או בערבות מדינה. הלוואה תקציבית מוגבלת בסכום ובתנאי זכאות, אבל הריבית נמוכה בהרבה.
```

**תשובה מוצעת (CPBG):**
```
ההבדל העיקרי? מי מממן ומי קובע את הריבית.

הלוואה תקציבית באה מפיקדון המעסיק שלך (מדינת ישראל), והריבית נקבעת על ידי החשב הכללי - כיום סביב 4.27%. זו הריבית הנמוכה ביותר שתמצא בשוק הישראלי. הבעיה? היא מוגבלת בסכום (עד 250,000 ש"ח) ויש תנאי זכאות נוקשים.

הלוואה עסקית רגילה היא מהבנק, בתנאי שוק (ריבית פריים + מרווח) או בערבות מדינה. הסכומים גבוהים יותר, התנאים יותר גמישים - אבל הריבית גבוהה יותר.

האידיאל? לשלב - הלוואה תקציבית לצרכים אישיים, הלוואה עסקית לעסק. ככה מנצלים את שני העולמות.
```

#### שאלה 4 - כותרת טובה ✅
```
"מה הריבית על הלוואות לעובדי מדינה בבנק יהב?"
```

**תשובה נוכחית:** רשימה טכנית

**תשובה מוצעת (CPBG):**
```
תלוי איזה מסלול בוחרים - יש פה טווח רחב:

**הלוואות תקציביות (החשכ"ל):** הריבית היא 4.27% - הנמוכה בשוק. זו ריבית מוסדרת, נקבעת על ידי משרד האוצר, ולא משתנה לפי "מיקוח" עם הבנק.

**הלוואות בערבות מדינה:** פריים + 2%-3%, כלומר כיום 7.5%-8.5%. נשמע גבוה? נכון - אבל התמורה היא ביטחונות נמוכים (10-15% במקום 100%). אם אין לך נכסים להעמיד, זה המסלול.

**מצטרפים חדשים:** אם אתה פותח חשבון עכשיו, יש הטבת הצטרפות - פריים מינוס 0.6% (כלומר כ-4.9%). זה תקף לתקופה מוגבלת.

תכל'ס? כדאי לבדוק כמה אפשרויות במקביל - כי יש מקרים שגוף אחר יציע לך תנאים טובים יותר בדיוק למקרה שלך.
```
